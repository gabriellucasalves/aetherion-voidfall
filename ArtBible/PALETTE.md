# Paleta

Base escura. Acento só onde há energia ou culto.

| Papel | Uso |
|--------|-----|
| Azul quase preto | Céu alto, buraco, olho vazio |
| Roxo escuro | Atmosfera, sombra de templo |
| Cinza frio / cinza violeta | Pedra da cidade |
| Mármore claro | Estátua, para separar da muralha |
| Verde musgo | Tempo. Mancha na quina, não tinta na silhueta inteira |
| Verde alienígena | Planta e fungo, pouco |
| Ciano | Cristal, portal, mecanismo ainda vivo |
| Dourado / laranja | Símbolo religioso e fogo raro |

Não introduzir uma cor nova num asset isolado. Se o cristal precisar de um tom, ele entra aqui antes de ir para o PNG.

Runtime atual do gerador (`Assets/Art/T1/build_t1.py`) já usa uma família próxima: `SKY_*`, `ST_*`, `MOSS`, `MARBLE`, `CRYS`, `GLYPH`. O kit desenhado à mão deve caber nessa família, não substituí-la por uma paleta de pintura.
